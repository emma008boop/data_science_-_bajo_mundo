
Es una de las fuertes de os. Automatizar la creacion o limpieza de directorios.

---------------------------------
os.mkdir("nombre") -> Crear una carpeta nueva 

os.makedirs("ruta/de/carpetas/anidadas") -> Crea una carpeta y tambien todas las carpetas intermediarias si no existen

os.listdir(ruta) -> te devuelve una lista con los nombres de todos los archivos y carpetas que estan dentro de la ruta que le des

os.remove("archivo.txt") -> Eliminar un archivo

os.rmdir("carpeta") -> Eliminar una <mark style="background: #ABF7F7A6;">carpeta que este vacia</mark>
